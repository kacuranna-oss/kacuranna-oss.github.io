Hi Jane Street, I'm Anna Katsur. I design brands, events and objects for technical audiences. 10+ years in tech design, including five years on the Yandex for Developers brand. Now at Mercuryo, a crypto fintech in London. Below are a few projects I think are relevant to you.

Most of them were made for Yandex, Russia’s largest technology company: search, maps, ride-hailing, cloud and AI, with a large engineering community of its own.

Yandex for Developers

// what it is

Yandex for Developers is a platform for the IT community, spanning conferences, meetups and professional development.

// challenge

Create one flexible identity that could work across different events, audiences and formats.

// solution

Developed a system based on programming syntax. Typography became the core visual language, supported by generative graphics, 3D and a flexible colour palette.

Yandex Cup ↗

// what it is

Yandex Cup is a competition where top developers solve complex, unconventional programming problems.

// challenge

Create a visual language that developers could recognise as their own — built around challenge, community and the joy of solving difficult problems.

// solution

Developed four creative directions exploring machine logic, emotion, programming culture and radical clarity. Ultra Clarity was selected as the final concept — a stripped-back system inspired by the precision and brevity of good code.

YaTalks

// what it is

YaTalks is Yandex’s flagship conference for the IT community, bringing together nearly 100 experts.

// challenge

Create one distinctive identity that could unite many topics, speakers and formats.

// solution

Developed “IT is the space of today” — technology as today’s territory of exploration and discovery. Translated into a visual system inspired by science fiction, spacecraft interfaces and abstract objects in interaction.

Yandex Team Merch

// what it is

Employee merch for Yandex.

// challenge

Go beyond individual merch items and create an evolving system.

// solution

Developed Merch as a Constructor. Each piece works independently but connects with past and future collections. Loops, carabiners and paracords form a shared design code, making the system modular and customisable.

From file to object. I prepare production files for textiles, apparel, jewellery, packaging, print and event build-outs, and work directly with manufacturers to get the details right.

Annual General Meeting Presentation

// what it is

Presentation for the Annual General Meeting of one of Eastern Europe’s largest banks.

// challenge

Turn a large volume of financial data into a clear, accurate story. Analyse and cross-check the numbers, structure the narrative, and align every detail with the bank’s finance team and CEO.

// solution

Developed the presentation from data to final delivery, combining financial analysis, storytelling and visual design. Worked across PowerPoint, Figma and Adobe — connecting different tools and formats into one production workflow.

Mercuryo Presentation System

// what it is

A company-wide presentation system for Mercuryo.

// challenge

Make presentations faster to create, consistent and on-brand across the company.

// solution

Developed ready-made structures, grids, styles and core slide types. Integrated with an LLM to help teams generate on-brand presentations faster — already used by half of the company.
